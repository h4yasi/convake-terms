# Convake（こんばけ）利用規約

本利用規約（以下「本規約」といいます）は、Discord Bot「Convake（こんばけ）」（以下「本Bot」といいます）の利用条件を定めるものです。本Botをサーバーに導入、またはコマンド等を利用した時点で、本規約のすべての内容に同意したものとみなします。

## 第2条（禁止事項：犯罪的使用および悪意ある負荷）
ユーザーは、本Botの利用にあたり、以下の行為を行ってはなりません。

1. **犯罪的・違法な使用の禁止**
   - 詐欺、フィッシング、不正アクセス、マルウェア・ウイルス・違法プログラム等の配布やリンク化など、犯罪行為または法令に違反する目的で本Botを使用する行為。
   - 犯罪を助長、教唆、または幇助する目的で本Botを使用する行為。
   - 児童ポルノ、児童虐待にあたるデータ、その他法令により所持・配布が禁じられている違法データを送信・処理・リンク化する行為。
2. **本Botへの悪意ある負荷・妨害行為の禁止**
   - マクロ、スクリプト、セルフボット、自動化ツール等を用いて短時間に大量のリクエストやスパム送信を行う行為。
   - 極端に巨大なファイル、異常な解像度・ピクセル数・ページ数・行数を持つデータ（いわゆる画像爆弾／Decompression Bomb等）、または意図的に破損・細工したデータを送信し、本Botのサーバー・メモリ・CPUに過大な負荷をかける行為。
   - 本Botのバグや不具合を悪用する行為、不正な解析・リバースエンジニアリング、その他本Botの正常な稼働および他のユーザーの利用を妨害する一切の行為。

## 第3条（データの取り扱い・一部データの保持・不正利用の禁止）
1. **通常の変換・編集コマンドにおける一時処理**
   - `/convert`、`/compress`、`/merge`、`/rotate`、`/flip`、`/watermark`、`/emoji`、`/sticker`、`/avatar_crop`、`/strip_exif`、`/palette` 等の変換・加工コマンドで送信されたファイルは、処理のためにメモリ上または一時領域で扱われ、結果の返却完了後に運営側で永続的に保存することはありません。
   - `/scan`（添付ファイル検査）において外部照会（VirusTotal等）が有効な場合、ファイル本体ではなくファイルのハッシュ値（SHA-256等）のみが照会されます。
2. **リンク化機能（`/link`）における一部データの保持**
   - `/link` コマンドを使用して画像・動画・テキストファイルをリンク化した場合、リンクの発行および `/link_list` による期限切れ後の再発行機能を提供するため、**運営者が管理する専用の非公開Discordチャンネル（保管用チャンネル）に当該ファイルデータが投稿・保持されます**。あわせて、ユーザーID・メッセージID・ファイル名・作成日時・保存期限等の履歴情報が記録されます。
   - 履歴の保存期限（無料会員：作成から30日間／プレミアム会員：作成から180日間 ※設定により変動する場合があります）が経過すると履歴一覧から自動的に除外され再発行できなくなりますが、システムの仕様上、保管用チャンネル上のメッセージデータ自体は期限経過後も残存する場合があります。
   - ユーザーは、`/link_delete` コマンドを実行することにより、自身の履歴情報および保管用チャンネルに保持された対象データ（画像・動画・ファイル本体）をいつでも削除することができます。
3. **保持データの不正利用の禁止**
   - 運営者は、本Botの処理過程で一時的に扱われるデータおよび `/link` 機能等により保管用チャンネルに保持される画像・動画・テキスト等のデータについて、**本Botの機能提供、障害対応、および規約違反・不正利用の確認といった運営管理目的以外で一切使用いたしません**。
   - 運営者がユーザーの画像やデータを**不正利用すること（無断での私的閲覧・収集・転載・公開、第三者への販売・提供・譲渡、AIモデルの学習データとしての利用等）は決して行いません**。
   - 法令に基づく公的機関からの正当な開示請求がある場合、または犯罪行為・重大な規約違反への対処として必要な場合を除き、保持データを第三者に開示・提供することはありません。
4. **リンク共有に関するご注意**
   - `/link` 機能はDiscordのCDN（添付ファイルURL）の仕組みを利用しています。発行されたURLを知っている第三者は、URLの有効期限内であれば誰でも該当ファイルを閲覧できるため、個人情報や機密情報、外部に公開したくない画像・ファイルは `/link` 機能に入力しないでください。
